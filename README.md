Modulo de Gestión de Gastos Personales

Objetivo
Sistema para el control y registro de finanzas personales, permitiendo el ingreso de egresos, categorizacion y generacion de reportes financieros

Entorno de Programacion
* Lenguaje: Python 3.11+
* Framework Backend: Django 5.0
* IDE Recomendado: Visual Studio Code
* Base de Datos: MySQL 8.0 / PostgreSQL
* Gestor de Dependencias: pip (virtualenv)

Instalación y Configuración
1. Clonar el repositorio: `git clone <Retos-del-Entorno-Distribuido-Problemas-Comunes>`
2. Crear un entorno virtual: `python -m venv venv`
3. Activar el entorno virtual:
   * Windows: `venv\Scripts\activate`
   * Linux/Mac: `source venv/bin/activate`
4. Instalar dependencias: `pip install -r requirements.txt`
5. Ejecutar migraciones: `python manage.py migrate`
6. Iniciar el servidor local: `python manage.py runserver`
